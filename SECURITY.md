## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please **DO NOT** open a public issue or pull request. Instead, follow our responsible disclosure process outlined below.

### How to Report

1. **GitHub Private Vulnerability Reporting (Preferred)**
   * Navigate to the main page of this repository on GitHub.
   * Click on the **Security** tab below the repository name.
   * In the left sidebar under "Reporting", click **Advisories**.
   * Click **Report a vulnerability** to fill out and submit the private form.

2. **Alternative Contact (Email)**
   * If you are unable to use GitHub's native reporting tool, please email your findings to `security@yourdomain.com`.

### What to Include in Your Report
To help us triage and resolve the issue quickly, please provide:
* A clear description of the vulnerability.
* Step-by-step instructions or proof-of-concept (PoC) code to reproduce it.
* The potential impact or what an attacker could achieve.

### Response Timeline and Updates

* **Initial Acknowledgment:** You will receive a response within **48 hours** confirming that we have received your report.
* **Status Updates:** We will provide an progress update every **7 days** while the vulnerability is being evaluated or remediated.

### What to Expect

* **If Accepted:** We will collaborate with you privately to develop a patch. Once a fix is ready, we will publish a GitHub Security Advisory and release a security update, ensuring you receive proper credit for the discovery.
* **If Declined:** If we determine the submission is a duplicate, non-vulnerability, or low-risk configuration issue, we will close the report with an explanation of our reasoning.
